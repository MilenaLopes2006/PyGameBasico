INSTRUÇÕES DO JOGO CATCH THE COINS: A CACHORRINHA QUE CAÇA MOEDAS

1) Entre no repositório: https://github.com/MilenaLopes2006/PyGameBasico
2) Acesse a pasta "CatchTheCoin".
3) Acesse o arquivo "CatchTheCoin_Oficial".
4) Copie e cole o código do arquivo "CatchTheCoin_Oficial".
5) Clique em "Run" para iniciar o jogo.
6) Utilize a tecla com a seta para direita para ir para a direita.
7) Utilize a tecla com a seta para esquerda para ir para a esquerda.
8) Utilizando essas teclas, ande com sua cachorrinha para esquerda e direita para pegar as moedas que caem no céu.
9) Ao finalizar cada nível, vá até a casinha e pressione a tecla "E" para descarregar as moedas na casinha e, assim, trocar de nível.
10) Ao finalizar as quatro fase clique em "R" para reiniciar o jogo.
11) Caso queira finalizar/fechar o jogo, clique na tecla "ESC".
